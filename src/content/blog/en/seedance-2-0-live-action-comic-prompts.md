## What is a live-action comic video?

Think "comic panels filmed like cinema": real-person look, exaggerated beats, clear 0–15s story arcs. Seedance 2.0 fits because it reads timed beats, camera moves, SFX, and @ references in one pass—ideal for vertical drama clips.

## Prompt formula (four blocks)

Split your prompt into four blocks so the model does not guess:

| Block | What to write |
| :--- | :--- |
| Character / look | Age, outfit, expression, injuries or makeup |
| Scene / time | Location, lighting, weather, key props |
| Timed storyboard | 0–3s / 3–7s / 7–15s actions and camera |
| Style / audio | Film look, lens, SFX, music, negative constraints (no subs, etc.) |

### 2. Period rebirth (wedding chamber)

Cinematic lighting, lip-sync, no subtitles or BGM—SFX only. Heroine realizes she returned three days before disaster.

## Tips before you generate

- Lock the face with a reference image—live-action comic lives or dies on consistency.  
- Write time blocks explicitly (0–3s, 3–7s…); vague "then he transforms" causes drift.  
- State negatives up front: no subtitles, no BGM, SFX only—cuts post work.

## FAQ

**Q: Do I need video references?**  
A: Not required. Text storyboards work; add @Video1 only when you need exact camera or motion copy.

**Q: Can prompts stay in Chinese on English UI?**  
A: Chinese prompts work well for period/wuxia scenes. Match prompt language to dialogue for cleaner lip-sync.

**Q: Why does armor assembly look messy?**  
A: Split into shorter clips or simplify mid-air phases. One 15s one-shot is demanding—reduce module count first.
