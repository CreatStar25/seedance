According to internal sources, **Seedance 2.1** is expected to officially launch in **late June 2026**. As an iterative version of Seedance 2.0, version 2.1 brings significant upgrades across multiple key dimensions. This article organizes the main upgrade points currently known to help you plan ahead.

---

## 1. Six Major Upgrade Directions of Seedance 2.1

### 1. Enhanced Physics Engine

Version 2.0 already introduced the physics engine concept, and version 2.1 is expected to further deepen details in object collision, fluid simulation, and cloth dynamics. This means realism in complex scenes will further improve, and multi-object interaction scenes will appear more natural.

### 2. Extended Video Duration Support

Currently, Seedance 2.0 supports generating videos up to 10 seconds per session. Version 2.1 is expected to extend this limit to 15-20 seconds. This upgrade direction is worth noting for creators who need longer continuous shots.

### 3. Enhanced Camera Control System

Version 2.0's camera controls already support basic movements such as dolly, orbit, and follow shots. Version 2.1 is expected to add more fine-grained camera parameter adjustments, such as:

- Precise focal length numerical control
- Custom camera movement curves
- Multi-camera sequence editing

### 4. Improved API Interface (seedance 2.0 api)

For enterprise users with development capabilities, the **API** interface of Seedance 2.1 will be a key optimization direction. More parameter control options are expected to be opened up, supporting more flexible system integration.

### 5. Optimized Multilingual Prompt Support

While Seedance has always had good support for Chinese prompts, version 2.1 is expected to make specialized optimizations for multilingual scenarios such as Japanese, Korean, and French, providing a smoother experience for non-Chinese users.

### 6. Improved Generation Speed

Through model compression and inference optimization, the generation efficiency of version 2.1 is expected to improve by 20%-30% compared to 2.0, reducing wait times.
