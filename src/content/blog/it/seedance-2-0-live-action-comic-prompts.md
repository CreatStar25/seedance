## Cos'è un video comic live-action?

Pannelli fumetto con persone reali, arco 0–15 s.

## Formula a quattro blocchi

Dividi in quattro:

| Blocco | Contenuto |
| :--- | :--- |
| Personaggio | Età, costume |
| Scena | Luogo, luce |
| Timeline | 0–3s / 3–7s / 7–15s |
| Stile/audio | Look, SFX, no subs |

## Sei tipi

| Tipo | Scena | Durata |
| :--- | :--- | :--- |
| Mecha | Città notte | 15s |
| Rinascita | Camera nuziale | 15s |
| Fantasy | Ricamo→tetto | 15s |
| Tokusatsu | Land desolata | 15s |
| Wuxia | Taverna | 15s |
| Confronto | Porta secta | 10–15s |
