## 1. Papan cerita jadual

Papan cerita ialah tulang belakang video. Jadual (tempoh, syot, kamera, cahaya/FX, bunyi) mengurangkan tekaan salah model.

**Langkah:**

1. Tentukan niche dan sudut (rutin selepas kerja, diari perjalanan, slice-of-life pejabat, dll.).  
2. Minta pembantu AI papan cerita **jadual**: tempoh, syot, kamera, cahaya/kesan, bunyi.  
3. Contoh prompt:

> Ikut rentak vlog animasi biasa, tulis papan cerita [vlog harian selepas kerja]: [pulang, masak, baca, tidur]. Suasana mesra. Jadual, bawah 15 saat, lajur: tempoh, syot, kamera, cahaya/kesan, bunyi.

4. **Tangkap skrin jadual** untuk dimuat naik ke Seedance 2.0.

**Contoh struktur:**

| Tempoh | Syot | Kamera | Cahaya/FX | Bunyi |
| :--- | :--- | :--- | :--- | :--- |
| 0–3s | Masuk apartmen, lampu hangat | Statik, push ringan | Dalaman hangat | Pintu, muzik lembut |
| 3–7s | Dapur memasak | Atas ke sisi | Api dapur, wap | Potong, kuali |
| 7–12s | Baca di sofa | Pan perlahan | Cahaya sisi | Muka surat, ambient |
| 12–15s | Padam lampu tidur | Tarik ke wide | Fade | Outro muzik |

## 2. Reka bentuk watak utama

Video AI gagal jika muka berubah setiap syot. Cipta **watak tetap** dengan teks-ke-imej.

**Contoh prompt:**

> Anda pereka watak anime. Wanita bandar ~25 tahun: rambut pendek, hidung tinggi, mata besar, ~165 cm, kulit biasa, sut kelabu muda, ilustrasi separuh badan, latar ringkas.

Simpan PNG/JPG bersama tangkapan skrin papan cerita.

![Papan cerita dan watak Seedance 2.0](https://img.seedance22.com/aiweb/seedance-260603-1.png)

## 3. Tetapkan Seedance 2.0

1. Buka penjanaan video, pilih **Seedance 2.0**.  
2. Mod **Rujukan penuh (全能参考)**—wajib untuk watak + papan cerita.  
3. Nisbah **9:16** atau **3:4** menegak; **16:9** melintang.  
4. 1080P jika pelan menyokong.

## 4. Muat naik dan jana

1. Dalam rujukan: **imej watak** + **tangkapan skrin papan cerita**.  
2. Prompt satu baris, contoh:

> Patuhi @Image1 untuk muka. Jana ikut urutan papan cerita @Image2. Gaya mesra, muka stabil, kurang gegar, 1080P.

3. Jana—biasanya tunggu **40–90 saat**.  
4. Satu syot gagal? Ubah baris jadual atau prompt sahaja.

**Nota:** Setiap janaan guna kredit; akaun baharu sering ada kredit harian percuma. Jangan klik berulang.

## 5. Pasca-produksi

Import ke editor (CapCut, Premiere…), sari kata, pelekat, BGM. Sediakan 10–15 minit untuk masa sari kata.

## 6. Ringkasan

| Fasa | Output | Petua |
| :--- | :--- | :--- |
| Perancangan | Topik | Mulakan sempit untuk siri |
| Papan cerita | Tangkapan jadual | Had tempoh, jelas kamera |
| Watak | Lembaran hero | Satu muka sepanjang video |
| Jana | Klip Seedance 2.0 | Rujukan penuh + @ jelas |
| Sunting | Sari kata & SFX | Tingkatkan siaran tonton habis |

Kitaran **Seedance 2.0**: **papan cerita → watak → Rujukan penuh → prompt → jana & sunting**.
