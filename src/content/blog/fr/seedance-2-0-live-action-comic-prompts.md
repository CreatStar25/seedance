## Qu'est-ce qu'une vidéo comic live-action ?

Des cases de BD filmées : personnages réalistes, arcs 0–15 s. Seedance 2.0 lit les blocs temporels et les @ refs.

## Formule en quatre blocs

Découpez en quatre blocs :

| Bloc | Contenu |
| :--- | :--- |
| Personnage | Âge, tenue, expression, blessures |
| Scène | Lieu, lumière, météo, props |
| Timeline | 0–3s / 3–7s / 7–15s action & caméra |
| Style/audio | Look, objectif, SFX, négatif (pas de subs) |

## Six types

| Type | Scène type | Durée |
| :--- | :--- | :--- |
| Transform mecha | Ville nocturne, saut, armure | 15s plan-séquence |
| Renaissance historique | Chambre nuptiale | 15s récit |
| Combat fantasy | Broderie → toit → cour | 15s action |
| Tokusatsu sombre | Wasteland, transform corps | 15s plan-séquence |
| Sauvetage wuxia | Taverne, baguettes | 15s action |
| Confrontation costume | Porte de secte | 10–15s |

## Six prompts copiables

### 1. Transform mecha

Saut depuis vaisseau furtif, assemblage armure en vol.

> Jeune Chinois, froid, blessures légères, tenue tactique noire. Nuit futuriste. 0–2s saut；2–5s chute；5–8s device poignet；8–12s modules；12–15s hover héroïque.

### 2. Renaissance historique

Lumière ciné, lip-sync, pas de subs/BGM.

> Qualité film, live-action. Pas de sous-titres. Chambre nuptiale antique. Réveil en robe rouge. Date mariage—3 jours avant chute ville. Retour réel.

### 3. Brodeuse vs ombre

Percussions orientales.

> Brodeuse (aiguille+fil cramoisi) vs bête ombre. 0–3s esquive；3–7s filet；7–15s cour. Tambours+guzheng.

### 4. Tokusatsu sombre

BLACKSUN, handheld.

> Tokusatsu dark, wasteland. 0–3s yeux bleu；3–6s DESCEND；9–12s armure；12–15s casque.

### 5. Wuxia taverne

Désaturé, handheld blur.

> 15s wuxia ciné. Taverne, baguettes projectile, bagarre. @Image1 femme robe noire part.

### 6. Standoff secte

Dialogue-driven.

> Cour de secte, jour. Violet : « Vous êtes avec lui ? » Bleu : « Le bien/mal n'est pas une faction. » Violet : « Ennemis alors. »
