## 1. Du « tirage aléatoire » à la « perspective du réalisateur »

**Seedance 2.0** adopte une architecture de référence multimodale : il ne s'agit plus de compter sur la chance avec une simple phrase, mais de pouvoir utiliser des images pour définir les personnages et les scènes, des vidéos pour définir les mouvements de caméra et les actions, et de l'audio pour définir la BGM et les effets sonores.  
Lors de la **génération vidéo par texte avec Seedance 2.0**, en utilisant conjointement les prompts et la syntaxe @, vous pouvez réaliser un contrôle de niveau réalisateur via « description textuelle + contraintes de référence ».

## 2. Capacités principales : 9 images + 3 vidéos + 3 fichiers audio

En mode « Référence complète » :

- Jusqu'à **9 images** : pour définir les personnages, les scènes et le style.  
- Jusqu'à **3 vidéos** : pour définir les mouvements de caméra, les actions et le rythme.  
- Jusqu'à **3 fichiers audio** : pour définir la BGM, les sons d'ambiance et les points de synchronisation.  

Utilisez **@nom_du_materiel** dans le prompt pour spécifier l'usage, par exemple : `@image1 comme première image`, `@video1 pour référence de mouvement de caméra`, `@audio1 pour extraire uniquement le son d'ambiance`.  
Ainsi, la **génération vidéo par texte de Seedance 2.0** exécutera selon votre intention, et non de manière aléatoire.

## 3. Workflow pratique de génération vidéo par texte (exemple)

1.  **Préparer les matériaux** : une image pour la première image, une vidéo de référence pour le mouvement de caméra, un effet sonore de référence (optionnel).  
2.  **Passer en mode Référence complète** : télécharger les matériaux, écrire clairement le prompt avec @ et le scénario.  
    - Exemple : @image1 comme première image ; @video1 pour référence de mouvement de caméra ; Scénario : La lumière du matin caresse le latte, la caméra avance lentement...  
3.  **Générer et itérer** : Après génération, vous pouvez affiner avec des mots-clés comme « ralenti » ou « tons chauds » et regénérer.

La **génération vidéo par texte pure avec Seedance 2.0** est également possible : saisissez uniquement une description textuelle, sans référence, idéal pour tester rapidement des idées ; pour un contrôle stable, il est recommandé d'ajouter des références d'image ou de vidéo.

## 4. Synchronisation audio-vidéo et rendu physique

**Seedance 2.0** prend en charge la génération audio-vidéo intégrée, permettant l'alignement des lèvres et des effets sonores ; il offre également de bonnes performances pour les mouvements physiques, les liquides, les tissus, etc., adapté aux scénarios de **génération vidéo par texte avec Seedance 2.0** exigeants en qualité comme la publicité ou les mini-séries.
