## O que é vídeo quadrinho live-action?

Painéis de HQ filmados com pessoas reais, arco 0–15 s.

## Fórmula em quatro blocos

Divida em quatro:

| Bloco | Conteúdo |
| :--- | :--- |
| Personagem | Idade, roupa, expressão |
| Cena | Local, luz |
| Timeline | 0–3s / 3–7s / 7–15s |
| Estilo/áudio | Look, SFX, sem legendas |
