## 1. Entrada

O JIMENG é a plataforma completa para o **Seedance 2.0**. Acesso direto: https://app.seedance22.com/generate/video-tools/seedance2.0

## 2. Dois modos

- **Frames inicial/final**: Faça upload de um frame inicial (ou frames inicial e final) + um prompt, e a IA gera o conteúdo intermediário. Ideal para **começar com o Seedance 2.0**.  
- **Referência completa**: Faça upload de múltiplas imagens/vídeos/áudios e use **@nome_do_material** no prompt para especificar o uso (ex: @vídeo1 para referência de movimento de câmera, @áudio1 para som de fundo). Ideal para consistência de personagens e controle de nível de direção.

## 3. Prompts e sintaxe @

- Descreva claramente: personagem principal, ambiente, ação, movimento de câmera, estilo.  
- Use @ para indicar a função de cada material, por exemplo: «@imagem1 como frame inicial» «@vídeo1 referência para este movimento de câmera».  
- Para geração pura de texto para vídeo, basta inserir texto; para controle estável, recomenda-se adicionar referências de imagem ou vídeo.
