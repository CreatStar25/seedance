## 1. 입구

즉몽(即梦)은 **Seedance 2.0**의 완전한 플랫폼입니다. 원클릭 입구: https://app.seedance22.com/generate/video-tools/seedance2.0

## 2. 두 가지 모드

- **시작/끝 프레임**: 시작 프레임(또는 시작/끝 프레임) 한 장을 업로드 + 프롬프트를 입력하면 AI가 중간 내용을 생성합니다. **Seedance 2.0** 입문에 적합합니다.
- **올인원 레퍼런스**: 여러 이미지/비디오/오디오를 업로드하고, 프롬프트에서 **@재료명**을 사용해 용도를 지정합니다(예: @비디오1 카메라 워크 참고, @오디오1 배경음). 캐릭터 일관성 유지와 감독급 제어에 적합합니다.

## 3. 프롬프트와 @ 문법

- 명확하게 작성: 주인공, 환경, 동작, 카메라 워크, 스타일.
- @를 사용해 각 재료의 역할을 지시합니다. 예: 「@이미지1 시작 프레임으로」「@비디오1 해당 카메라 워크 참고」.
- 순수 텍스트로 비디오 생성 시 텍스트만 입력하면 됩니다. 안정적인 제어를 원한다면 이미지나 비디오 레퍼런스를 추가하는 것이 좋습니다.
