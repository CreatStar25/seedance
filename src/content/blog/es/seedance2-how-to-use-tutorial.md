## 1. Entrada

JIMENG es la plataforma completa para **Seedance 2.0**. Acceso directo: https://app.seedance22.com/generate/video-tools/seedance2.0

## 2. Dos modos

- **Fotogramas inicial y final**: Sube una imagen inicial (o inicial y final) + un prompt, y la IA genera el contenido intermedio. Ideal para empezar con **Seedance 2.0**.
- **Referencia completa**: Sube múltiples imágenes/videos/audios y especifica su uso en el prompt con **@nombre_del_material** (por ejemplo, @video1 para referencia de movimiento de cámara, @audio1 para sonido de fondo). Perfecto para consistencia de personajes y control de nivel de director.

## 3. Prompts y sintaxis @

- Describe claramente: personaje principal, entorno, acción, movimiento de cámara, estilo.
- Usa @ para indicar la función de cada material, por ejemplo: «@imagen1 como fotograma inicial» «@video1 referencia este movimiento de cámara».
- Para generar video solo con texto, puedes ingresar solo el prompt; para un control más estable, se recomienda añadir referencias de imagen o video.
