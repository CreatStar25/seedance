## 1. Від «випадкового створення» до «режисерського погляду»

**Seedance 2.0** використовує мультимодальну референсну архітектуру: замість того, щоб покладатися лише на удачу з одним текстовим описом, ви можете використовувати зображення для визначення персонажів та сцен, відео — для задання руху камери та дій, а аудіо — для визначення музики та звукових ефектів.
Під час **генерації відео з тексту в Seedance 2.0**, комбінуючи текстові підказки з синтаксисом @, ви досягаєте режисерського контролю за принципом «текстовий опис + обмеження за посиланням».

## 2. Ключові можливості: 9 зображень + 3 відео + 3 аудіо

У режимі «Універсальне посилання»:

-   До **9 зображень**: для визначення персонажів, сцен та стилю.
-   До **3 відеофрагментів**: для задання руху камери, дій та ритму.
-   До **3 аудіофрагментів**: для визначення музики, фонового звуку та синхронізації.

У тексті підказки використовуйте **@назва_матеріалу**, щоб вказати призначення, наприклад: `@зображення1 як перший кадр`, `@відео1 для посилання на рух камери`, `@аудіо1 лише для виділення фонового звуку`.
Таким чином, **генерація відео з тексту в Seedance 2.0** виконуватиметься згідно з вашим задумом, а не випадковим чином.

## 3. Практичний воркфлоу генерації відео з тексту (приклад)

1.  **Підготуйте матеріали**: одне зображення для першого кадру, один відеофрагмент для посилання на рух камери, один аудіофрагмент для посилання на звук (опціонально).
2.  **Увімкніть режим «Універсальне посилання»**: завантажте матеріали та чітко опишіть сценарій у тексті підказки, використовуючи @.
    -   Приклад: @зображення1 як перший кадр; @відео1 для посилання на рух камери; Сценарій: ранкове сонце освітлює лате, камера повільно наближається...
3.  **Генерація та ітерація**: після генерації ви можете уточнити результат за допомогою ключових слів, таких як «сповільнений рух» або «теплі тони», і згенерувати знову.

Також можлива **чиста генерація відео з тексту в Seedance 2.0**: просто введіть текстовий опис без завантаження референсів, що підходить для швидкої перевірки ідей. Для стабільного контролю рекомендується додавати зображення або відео-посилання.

## 4. Синхронізація аудіо та відео та фізична реалістичність

**Seedance 2.0** підтримує інтегровану генерацію аудіо та відео, синхронізуючи рухи губ та звукові ефекти. Також добре відтворює фізичний рух, рідини, тканину тощо, що робить його придатним для **генерації відео з тексту в Seedance 2.0** у сценаріях, що вимагають високої якості, таких як реклама чи короткометражні відео.
