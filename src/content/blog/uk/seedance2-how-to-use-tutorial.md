## 1. Вхід

JIMENG є повноцінною платформою для **Seedance 2.0**. Пряме посилання: https://app.seedance22.com/generate/video-tools/seedance2.0

## 2. Два режими

- **Перший/останній кадр**: Завантажте один початковий кадр (або початковий та кінцевий кадри) + текстовий опис, і AI згенерує проміжний вміст. Ідеально підходить для **ознайомлення з Seedance 2.0**.  
- **Універсальне посилання**: Завантажте кілька зображень/відео/аудіофайлів і вкажіть їх призначення в текстовому описі за допомогою синтаксису **@назва_матеріалу** (наприклад, @відео1 для посилання на рух камери, @аудіо1 для фонової музики). Ідеально підходить для підтримки консистентності персонажів та режисерського контролю.

## 3. Текстові описи (промпти) та синтаксис @

- Чітко опишіть: головного героя, середовище, дії, рух камери, стиль.  
- Використовуйте @, щоб вказати роль кожного матеріалу, наприклад: «@зображення1 як початковий кадр», «@відео1 посилатися на цей рух камери».  
- Для чистого створення відео з тексту достатньо ввести лише текст; для стабільного контролю рекомендується додавати зображення або відео для посилання.
