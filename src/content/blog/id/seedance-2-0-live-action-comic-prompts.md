## Apa itu video komik live-action?

Panel komik difilmkan dengan orang nyata, arc 0–15 detik.

## Formula empat blok

Bagi empat:

| Blok | Isi |
| :--- | :--- |
| Karakter | Usia, kostum, ekspresi |
| Adegan | Lokasi, cahaya |
| Timeline | 0–3s / 3–7s / 7–15s |
| Gaya/audio | Look, SFX, tanpa subtitle |

## Enam tipe

| Tipe | Adegan | Durasi |
| :--- | :--- | :--- |
| Transform mecha | Kota malam | 15s |
| Rebirth | Kamar pengantin | 15s |
| Fantasi | Bordir→atap | 15s |
| Tokusatsu | Gurun | 15s |
| Wuxia | Kedai | 15s |
| Konfrontasi | Gerbang sekte | 10–15s |

## Enam prompt

### 1. Mecha

Lompat dan armor.

> Pria muda China, luka ringan, pakaian taktis. 0–2s lompat；2–5s jatuh；5–8s device；8–12s modul；12–15s hover.

### 2. Rebirth

Cahaya film, tanpa subtitle.

> Kualitas film. Kamar pengantin. Bangun dengan gaun merah. Tanggal—3 hari sebelum.

### 3. Penjahit vs bayangan

Drum oriental.

> Penjahit vs monster bayangan. 0–3s hindar；3–7s jaring；7–15s halaman.

### 4. Tokusatsu

BLACKSUN.

> Tokusatsu gelap. 0–3s mata；3–6s DESCEND；9–12s armor.

### 5. Wuxia

Desaturasi.

> 15s wuxia. Kedai, sumpit, keroyokan. @Image1 pergi.

### 6. Konfrontasi

Dialog.

> Halaman sekte. Ungu: «Bersama dia?» Biru: «Benar bukan pihak.»
