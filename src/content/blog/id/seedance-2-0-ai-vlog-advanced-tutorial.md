## 1. Storyboard tabel

Storyboard adalah tulang punggung video. Tabel (durasi, shot, kamera, cahaya/FX, suara) mencegah tebakan model yang salah.

**Langkah:**

1. Tentukan niche dan sudut (rutinitas setelah kerja, jurnal perjalanan, slice-of-life kantor, dll.).  
2. Minta asisten AI storyboard **tabel**: durasi, shot, kamera, cahaya/efek, suara.  
3. Contoh prompt:

> Dengan ritme vlog animasi umum, tulis storyboard [vlog harian setelah kerja]: [pulang, masak, baca, tidur]. Hangat dan nyaman. Tabel, di bawah 15 detik, kolom: durasi, shot, kamera, cahaya/efek, suara.

4. **Screenshot tabel** dan simpan untuk diunggah ke Seedance 2.0.

**Contoh struktur:**

| Durasi | Shot | Kamera | Cahaya/FX | Suara |
| :--- | :--- | :--- | :--- | :--- |
| 0–3s | Masuk apartemen, lampu hangat | Statis, push ringan | Interior hangat | Pintu, musik lembut |
| 3–7s | Dapur memasak | Top ke samping | Api kompor, uap | Potong, wajan |
| 7–12s | Baca di sofa | Pan lambat | Cahaya samping | Halaman, ambient |
| 12–15s | Matikan lampu tidur | Pull back wide | Fade | Musik outro |

## 2. Desain karakter utama

Video AI gagal jika wajah berubah tiap shot. Buat **karakter tetap** dengan text-to-image.

**Contoh prompt:**

> Anda desainer karakter anime. Wanita urban ~25 tahun: rambut pendek, hidung tegas, mata besar, ~165 cm, kulit normal, set abu muda, ilustrasi setengah badan, latar bersih.

Simpan PNG/JPG bersama screenshot storyboard.

![Storyboard dan karakter Seedance 2.0](https://img.seedance22.com/aiweb/seedance-260603-1.png)

## 3. Atur Seedance 2.0

1. Buka pembuatan video, pilih **Seedance 2.0**.  
2. Mode **Referensi penuh (全能参考)**—wajib untuk karakter + storyboard.  
3. Rasio **9:16** atau **3:4** vertikal; **16:9** horizontal.  
4. 1080P jika paket mendukung.

## 4. Unggah dan hasilkan

1. Di referensi: **gambar karakter** + **screenshot storyboard**.  
2. Prompt satu baris, contoh:

> Ikuti @Image1 untuk wajah. Urutkan sesuai storyboard @Image2. Gaya hangat, wajah stabil, minim goyah, 1080P.

3. Hasilkan—biasanya tunggu **40–90 detik**.  
4. Satu shot gagal? Edit baris tabel atau prompt saja.

**Catatan:** Setiap generate memakai kredit; akun baru sering dapat kredit harian gratis. Jangan klik berulang.

## 5. Pasca-produksi

Impor ke editor (CapCut, Premiere…), subtitle, stiker, BGM. Sisihkan 10–15 menit untuk timing subtitle.

## 6. Ringkasan

| Tahap | Output | Tips |
| :--- | :--- | :--- |
| Rencana | Topik | Mulai sempit untuk serial |
| Storyboard | Screenshot tabel | Batasi durasi, jelaskan kamera |
| Karakter | Sheet hero | Satu wajah sepanjang video |
| Generate | Klip Seedance 2.0 | Referensi penuh + @ jelas |
| Edit | Subtitle & SFX | Tingkatkan completion |

Loop **Seedance 2.0**: **storyboard → karakter → Referensi penuh → prompt → generate & edit**.
