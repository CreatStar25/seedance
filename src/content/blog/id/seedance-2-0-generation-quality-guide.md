## Kekuatan render teks di Seedance 2.0

### 1. Render cerdas berbasis AI

Mendeteksi font, ukuran, dan konteks lalu menyesuaikan smoothing tepi dan kontras ke resolusi output.

### 2. Ketajaman sesuai adegan

Video FPS tinggi: stabilitas antar-frame; poster statis: tepi lebih tajam.

| Adegan | Masalah umum | Fokus Seedance 2.0 |
| :--- | :--- | :--- |
| Subtitle short | Smear saat putar cepat | Stabilitas frame, kontrol motion blur |
| Poster / cover | Font kecil bergerigi | Anti-aliasing, boost kontras |
| Subtitle live | Lag, goresan putus | Render latensi rendah, kontinuitas |

## Praktik: langkah mempertajam teks

### 1. Sesuaikan parameter

1. Buka pengaturan teks/subtitle dan cari **Peningkatan ketajaman**.  
2. Pilih preset: vertikal, horizontal, atau cetak.  
3. Aktifkan **anti-aliasing tepi** untuk font kecil.  
4. Samakan **adaptasi resolusi** dengan target (1080p, 4K).

### 2. Nyatakan kebutuhan teks di prompt

Saat generate, jelaskan gaya subtitle. Contoh:

> Subtitle putih outline hitam di bawah, ukuran sedang, goresan tajam, tanpa smear, 1080p.

Masih buram? Periksa teks buram di referensi, export di bawah preview, atau mode cepat tanpa kualitas.

## FAQ

**T: Font apa yang dioptimalkan?**  
J: Serif/sans umum dan display pemasaran. Font sangat tipis: pratinjau sebelum batch.

**T: Perlu hardware khusus?**  
J: Browser biasa cukup. Batch besar lewat antrean generator.

**T: Ketajaman memperlambat render banyak?**  
J: Preset standar: dampak kecil. Ketajaman maksimal skala besar: stagger atau segmentasi.
