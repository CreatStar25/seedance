## Wat is een live-action comic video?

Comic panelen met echte mensen, 0–15 s boog.

## Vier-blokken formule

Deel in vier:

| Blok | Inhoud |
| :--- | :--- |
| Personage | Leeftijd, kostuum |
| Scène | Locatie, licht |
| Timeline | 0–3s / 3–7s / 7–15s |
| Stijl/audio | Look, SFX, geen subs |
