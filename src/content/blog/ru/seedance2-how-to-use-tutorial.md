## 1. Вход

JIMENG — это полноценная платформа для **Seedance 2.0**. Прямая ссылка для входа: https://app.seedance22.com/generate/video-tools/seedance2.0

## 2. Два режима

- **Начальный и конечный кадр**: Загрузите один начальный кадр (или начальный и конечный кадры) + промпт, и AI сгенерирует промежуточное содержимое. Подходит для **знакомства с Seedance 2.0**.  
- **Универсальная ссылка**: Загрузите несколько изображений/видео/аудиофайлов и укажите их назначение в промпте с помощью синтаксиса **@имя_материала** (например, @видео1 для ссылки на движение камеры, @аудио1 для фонового звука). Подходит для поддержания согласованности персонажей и режиссёрского контроля.

## 3. Промпты и синтаксис @

- Чётко опишите: главного героя, окружение, действие, движение камеры, стиль.  
- Используйте @, чтобы указать назначение каждого материала, например: «@изображение1 как начальный кадр», «@видео1 использовать это движение камеры».  
- Для чистой генерации видео из текста можно ввести только текст; для стабильного контроля рекомендуется добавить изображение или видео в качестве ссылки.
