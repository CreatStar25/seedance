## 1. От «случайной генерации» к «режиссёрскому взгляду»

**Seedance 2.0** использует мультимодальную референсную архитектуру: больше не нужно полагаться на удачу с одним текстовым промптом. Теперь вы можете использовать изображения для фиксации персонажей и сцен, видео — для определения движения камеры и действий, аудио — для задания фоновой музыки и звуковых эффектов.
При **создании видео из текста в Seedance 2.0** совместное использование промптов и синтаксиса **@** позволяет реализовать режиссёрский контроль по принципу «текстовое описание + р��ференсные ограничения».

## 2. Ключевые возможности: 9 изображений + 3 видео + 3 аудио

В режиме «Всеобъемлющие референсы»:

- До **9 изображений**: для фиксации персонажей, сцен и стиля.
- До **3 видеофрагментов**: для определения движения камеры, действий и ритма.
- До **3 аудиодорожек**: для задания фоновой музыки, атмосферных звуков и синхронизации.

В промпте используйте синтаксис **@имя_материала** для указания назначения, например: `@изображение1 как первый кадр`, `@видео1 как референс для движения камеры`, `@аудио1 только для извлечения атмосферных звуков`.
Таким образом, **генерация видео из текста в Seedance 2.0** будет выполняться согласно вашему замыслу, а не случайным образом.

## 3. Практический процесс создания видео из текста (пример)

1.  **Подготовьте материалы**: одно изображение для первого кадра, одно видео как референс для движения камеры, один аудиофайл для звуковых эффектов (опционально).
2.  **Перейдите в режим «Всеобъемлющие референсы»**: загрузите материалы, в промпте чётко укажите назначение через @ и опишите сюжет.
    *   Пример: @изображение1 как первый кадр; @видео1 как референс для движения камеры; Сюжет: утреннее солнце освещает латте, камера медленно приближается...
3.  **Генерация и итерация**: после генерации можно выполнить тонкую настройку, добавив ключевые слова, такие как «замедленная съёмка» или «тёплые тона», и сгенерировать заново.

Чистая **генерация видео из текста в Seedance 2.0** также возможна: просто введите текстовое описание без загрузки референсов. Это подходит для быстрой проверки идей. Для стабильного контроля рекомендуется добавлять изображения или видео в качестве референсов.
