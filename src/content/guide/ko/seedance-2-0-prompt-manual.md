Seedance 2.0은 이미지·영상·오디오·텍스트를 입력할 수 있는 AI 영상 생성 모델입니다. 본문은 **Seedance 2.0 프롬프트 작성법**과 사용 포인트를 정리합니다.

## 1. Seedance 2.0 파라미터 및 기능 개요

| 항목 | 내용 |
|------|------|
| 이미지 입력 | 최대 9장 |
| 영상 입력 | 최대 3개, 총 15초 이내 |
| 오디오 입력 | MP3, 최대 3개, 총 15초 이내 |
| 텍스트 입력 | 자연어 프롬프트 |
| 생성 길이 | 4~15초 선택 |
| 음향 출력 | 효과음/BGM 지원 |

혼합 입력 시 총 12개 파일까지 가능하며, 화면·리듬에 영향이 큰 소재를 우선 업로드하세요.

## 3. 멀티모달과 Seedance 2.0 프롬프트 작성

### 1) 멀티모달 참조

텍스트·이미지·영상·오디오를 “사용 대상” 또는 “참조 대상”으로 업로드할 수 있습니다. **Seedance 2.0 프롬프트**에 동작·효과·운경·인물·장면·소리를 명확히 쓰면 모델이 이해합니다.

- 참조 이미지: 구도·캐릭터 디테일 복원  
- 참조 영상: 촬영 언어, 동작 리듬, 크리에이티브 효과 복제  
- 영상은 부드럽게 연장·이어 “이어서 촬영” 지원  
- 편집: 캐릭터 교체, 삭제, 추가

소재가 많을 때는 프롬프트에서 **@图1、@视频1** 등으로 대응 관계를 밝혀 두세요.

### 2) 자주 쓰는 작성 예

- **첫 프레임/끝 프레임 + 참조 영상 동작**  
  “@图1을 첫 프레임으로, @视频1의 격투 동작 참조”

- **기존 영상 연장**  
  “@视频1을 5초 연장”(생성 길이는 “추가 구간” 길이만, 예: 5초)

- **여러 영상 융합**  
  “@视频1과 @视频2 사이에 장면 추가, 내용은……”

- **연속 동작**  
  “캐릭터가 점프에서 회전으로 자연스럽게 이어지게. @图1 @图2 @图3”

### 3) 일관성, 운경, 크리에이티브 복제

Seedance 2.0은 얼굴·의상·장면·촬영 스타일을 잘 유지하며, 고난도 운경·복잡 동작 참조 복제를 지원합니다. 크리에이티브 전환, 광고 완성본, 영화 장면 등은 참조 그림·영상을 준비한 뒤 프롬프트에 “@视频1의 리듬과 운경 참조, @图1의 캐릭터”라고 쓰면 됩니다.

## 4. 요약

**Seedance 2.0 프롬프트**의 핵심은 “무엇을 참조해 무엇을 할지”를 분명히 하고, @로 소재를 묶는 것입니다. 멀티모달과 정확한 지시로 제작을 더 잘 제어하고 효율적으로 할 수 있습니다.
