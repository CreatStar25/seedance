Seedance 2.0 เป็นโมเดลสร้างวิดีโอ AI รองรับภาพ วิดีโอ เสียง และข้อความสำหรับการควบคุมที่สมบูรณ์ขึ้น คู่มือนี้อธิบาย **วิธีเขียน prompt Seedance 2.0** และได้ผลลัพธ์ที่ดีที่สุด

## 1. พารามิเตอร์และความสามารถ Seedance 2.0

| มิติ | สเปก |
|------|------|
| อินพุตภาพ | ≤ 9 ภาพ |
| อินพุตวิดีโอ | ≤ 3 คลิป รวม ≤ 15 วินาที |
| อินพุตเสียง | MP3 ≤ 3 ไฟล์ รวม ≤ 15 วินาที |
| อินพุตข้อความ | prompt ภาษาธรรมชาติ |
| ระยะเวลาออก | 4–15 วินาที เลือกได้ |
| เอาต์พุตเสียง | SFX/เพลง รองรับ |

อินพุตผสมจำกัด 12 ไฟล์ ให้ลำดับความสำคัญกับแอสเซ็ตที่กระทบลุคและจังหวะมากที่สุด

## 2. ความสามารถหลัก: เสถียร ลื่น สมจริง

Seedance 2.0 ปรับปรุงฟิสิกส์ ความลื่นของโมชัน การทำตามคำสั่ง และความสม่ำเสมอของสไตล์ จัดการโมชันซับซ้อนและต่อเนื่องได้ดี

**ตัวอย่าง prompt:** สาวตากผ้าอย่างสง่างาม แล้วหยิบอีกชิ้นจากถังมากรองแรงๆ

## 3. มัลติโมดัลและการเขียน Prompt Seedance 2.0

### 3.1 อ้างอิงมัลติโมดัล

คุณอัปโหลดข้อความ ภาพ วิดีโอ และเสียงเป็นแอสเซ็ตหลักหรืออ้างอิงได้ ระบุชัดใน **prompt Seedance 2.0** ว่าอ้างอิงอะไร (โมชัน เอฟเฟกต์ กล้อง ตัวละคร ฉาก เสียง)

- ภาพอ้างอิง: คอมโพสิชันและรายละเอียดตัวละคร  
- วิดีโออ้างอิง: ภาษากล้อง จังหวะโมชัน เอฟเฟกต์สร้างสรรค์  
- วิดีโอขยายและต่อเนื่องได้ลื่นไหล (“ถ่ายต่อ”)  
- ตัดต่อ: เปลี่ยนตัวละคร ตัด เพิ่ม

เมื่อใช้แอสเซ็ตหลายอย่าง ใช้ **@image1** **@video1** ฯลฯ ใน prompt ให้โมเดลรู้ว่าอันไหนคืออันไหน

### 3.2 รูปแบบ prompt ทั่วไป

- **เฟรมแรก/สุดท้าย + โมชันวิดีโออ้างอิง**  
  “@image1 เป็นเฟรมแรก อ้างอิงโมชันต่อสู้ @video1”

- **ขยายวิดีโอที่มีอยู่**  
  “ขยาย @video1 อีก 5 วินาที” (ตั้งระยะเวลาออกเฉพาะส่วนใหม่ เช่น 5 วินาที)

- **รวมวิดีโอหลายคลิป**  
  “เพิ่มฉากระหว่าง @video1 กับ @video2 เนื้อหา: …”

- **แอ็กชันต่อเนื่อง**  
  “ตัวละครเปลี่ยนจากกระโดดตรงไปเป็นตีลังกา ให้โมชันลื่นไหล @image1 @image2 @image3”

### 3.3 ความสม่ำเสมอ กล้อง และการจำลองสร้างสรรค์

Seedance 2.0 รักษาหน้า เสื้อผ้า ฉาก และสไตล์กล้องให้สม่ำเสมอ และจำลองงานกล้องและโมชันซับซ้อนจากอ้างอิงได้ สำหรับการเปลี่ยนฉากสร้างสรรค์ ช็อตสไตล์โฆษณาหรือคลิปหนัง ระบุใน prompt ว่า “อ้างอิงจังหวะและกล้อง @video1 ตัวละคร @image1”

## 4. สรุป

**การเขียน prompt Seedance 2.0** สรุปคือ: ระบุชัดว่าอ้างอิงอะไรและทำอะไร และใช้ @ ผูกแอสเซ็ต อินพุตมัลติโมดัลบวกคำสั่งแม่นยำทำให้การสร้างควบคุมได้และมีประสิทธิภาพมากขึ้น
